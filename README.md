Prompt Manager 是一款免费开源的用户脚本，为 AI 聊天页面增加通用提示词管理器。支持多个主流 AI 平台，支持动态提示词、AI 优化提示词、外部提示词订阅更新、Gist 导入导出、备份恢复。

## 支持的平台

| --- | --- |
| DeepSeek | chat.deepseek.com |
| 豆包 | doubao.com |

| Kimi | kimi.com |
