Prompt Manager 是一款免费开源的用户脚本，为 AI 聊天页面增加提示词库。

可在 ChatGPT、Claude、Gemini、DeepSeek、Kimi、豆包、千问等主流 AI 平台上保存、整理和复用提示词。支持动态提示词（变量、选项列表、文件槽位）、AI 优化提示词、带更新检查的提示词订阅，以及 GitHub Gist 分享。

## 功能

- **提示词库**：新建、编辑、复制、删除、置顶、拖拽排序，支持搜索、悬停预览，以及普通列表和展开列表（1–3 列）。
- **标签与排序**：彩色标签、标签筛选、自定义标题颜色；可按名称、最新/最早、最常用/最少用、标签分组排序。
- **动态提示词**：变量、选项列表、文件槽位、日期时间宏（语法见下文）。
- **行内调用**：在聊天输入框中输入 `#` 加关键词，即可搜索并插入提示词。
- **自动发送**：可选择插入后立即发送。
- **自动附加文件**：可为提示词绑定已保存的全局文件，或通过 `#file` 槽位在每次使用时上传。粘贴按钮也可读取剪贴板中的文本和图片。
- **AI 优化提示词**：使用你自己的 OpenAI 兼容接口改写提示词，应用前可在左右对比视图中查看差异。
  - 支持多套 API 配置（名称、Base URL、API Key、模型、系统提示词）。
  - 每套配置可填多个 API Key（逗号或空格分隔），会自动轮换使用。
  - 可用 `标题 (备注) {{ 提示词 }}` 定义多个系统提示词，每次使用时选择其一。
- **外部提示词**：将提示词关联到 JSON 元数据 URL（Gist / GitHub / GitLab / jsDelivr），支持版本号、更新日志和定时检查更新。
- **Gist 集成**：直接在 gist.github.com 上导入或导出提示词（`.mp.prompt.json` / `.txt` / `.md`）。
- **智能预测与语法高亮**：编辑器内自动补全括号，并建议变量和宏。
- **备份与恢复**：可按类别导出或导入 `.mp.backup.json`。
- **个性化**：自动/亮色/暗色主题，简体中文和英文界面，支持单个提示词快捷键和全局快捷键。

## 使用方法

脚本会在聊天输入框工具栏中加入一个提示词按钮（找不到工具栏时回退为悬浮按钮）：

| 操作 | 结果 |
| --- | --- |
| 点击按钮 | 打开提示词列表 |
| 悬停按钮 | 展开 **优化**（AI）和 **粘贴** 快捷按钮 |
| 点击某条提示词 | 插入到输入框（动态提示词会先弹出填写窗口） |
| 悬停某条提示词 | 显示预览，以及编辑 / 复制 / 删除 / 移动 / 置顶操作 |

### 默认快捷键

所有快捷键均可在 **设置 → 高级** 中修改。

| 快捷键 | 功能 |
| --- | --- |
| `Alt+N` | 新建提示词 |
| `Alt+P` | 打开提示词列表并聚焦搜索 |
| `Ctrl+Alt+P` | 以展开模式打开提示词列表 |
| `Alt+E` | 用 AI 优化当前输入 |
| `Ctrl+Enter` | 保存并发送当前提示词 |
| `Ctrl+S` | 保存提示词但不关闭编辑器 |
| `Shift+Enter` | 在动态提示词窗口中换行 |

每条提示词也可以设置独立快捷键（编辑器 → 快捷键 栏）。

### 动态提示词语法

在提示词编辑器中开启 **动态提示词** 后，可使用以下语法。

| 语法 | 含义 |
| --- | --- |
| `[标签]` | 自由文本输入 |
| `[标签::默认值]` | 带默认值的输入 |
| `[标签](说明)` | 带说明提示的输入 |
| `[标签 = $var]` | 输入值存入 `$var`，提示词中所有 `$var` 都会被替换 |
| `{标签 = $var}` | 静默变量：询问取值，但不在原位置插入 |
| `#start ... #end` | 选项块（多行，或用 `//` 分隔的单行写法） |
| `# 标题` | 选项块内的分组标题 |
| `+ [选项]` | 多选项 |
| `- [选项]` | 互斥选项（选中后清除其他选项） |
| `1[选项]` | 编号相同的选项互斥 |
| `[#]` | 自由输入的"其他"选项 |
| `[选项::x]` | 默认勾选 |
| 选项后的 `'文本'` | 选中该选项时插入的自定义文本（可含 `[输入框]`） |
| `#ignore ... #end` | 原样输出其中内容 |
| `''文本''` | 字面文本（变量仍会被替换） |
| `\#` `\[` `\]` `\{` `\}` | 转义特殊字符 |
| `#date` / `#time` | 当前日期 / 时间；加 `-DD`、`-MM`、`-YY`、`-HH`、`-SS` 后缀可隐藏对应部分；`#date+time` 同时输出两者 |
| `#file(标题)` | 每次使用时的文件上传槽位 |

示例：

```text
把下面的文本翻译成 [目标语言 = $lang::英文]。
#start
# 语气
- [正式]
- [口语]
[#]
#end
只使用 $lang。今天是 #date。
```

## 隐私与安全

- 提示词、标签、文件、设置和 API Key 都保存在你的用户脚本管理器本地存储中。
- 脚本没有任何遥测，不会收集或上传你的数据。
- 仅在两种情况下会发起网络请求：
  - **AI 优化**：把提示词发送到你配置的 Base URL。
  - **外部提示词 / Gist**：从 `raw.githubusercontent.com`、`gist.githubusercontent.com`、`cdn.jsdelivr.net` 或 `gitlab.com` 获取元数据、提示词和更新日志。
- 脚本声明了 `@connect *`，以便支持自定义 API 地址。请只配置你信任的接口。
- 导入备份前请先备份当前数据；导入会覆盖所选类别。
